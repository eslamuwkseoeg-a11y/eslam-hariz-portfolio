# Eslam Hariz — SEO Portfolio

## Files
- `index.html` — website structure and SEO metadata
- `style.css` — responsive dark design
- `script.js` — mobile navigation and reveal animations
- `cv/` — put your real CV PDF here and name it `Eslam-Hariz-CV.pdf`

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your email.
2. Replace `YOUR-LINKEDIN` with your LinkedIn profile slug.
3. Replace `YOUR_WHATSAPP_NUMBER` with your international number (digits only, e.g. 2010xxxxxxx).
4. Verify that the project names and descriptions accurately reflect your work.
5. Add your real CV PDF to `cv/Eslam-Hariz-CV.pdf`.
6. Update canonical and Open Graph URLs if you change the Netlify site name.

## Deploy on Netlify
Drag the entire `eslam-hariz-seo-portfolio` folder (or its ZIP contents) into Netlify's manual deploy area. The `index.html` file must be at the root of the deployed folder.
